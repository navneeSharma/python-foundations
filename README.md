# Python Foundations — 100 Practice Problems

This repository is a structured refresh of my core Python programming fundamentals through approximately 100 practice problems.

I already use Python in the context of Data Science, Machine Learning, AI, data analysis, and related projects. 
However, I noticed, while working with higher-level libraries and frameworks, it is easy to rely heavily on tools such as Pandas, NumPy, Scikit-learn, without revisiting the underlying programming concepts regularly.

I created this repository to deliberately strengthen those foundations again.

The goal is not to learn Python for the first time, but to revisit the fundamentals, improve problem-solving fluency, and make sure that I am comfortable solving problems using core Python without unnecessarily depending on external libraries.

## Why This Repository?

As I continue developing my skills in Data Science and AI, I wanted to reinforce the programming foundation underneath them.

This practice focuses on concepts such as:

* Variables and data types
* Arithmetic and logical operations
* Conditional statements
* Loops
* Strings
* Lists, tuples, sets, and dictionaries
* Functions
* Basic problem solving
* Input validation
* Pattern-based exercises
* File handling
* Other core Python concepts

Rather than simply reading syntax again, I am working through problems and implementing the solutions myself.

## Approach

For most exercises, I try to:

1. Understand the problem before writing code.
2. Build a simple working solution first.
3. Review the logic behind the solution.
4. Explore alternative approaches when useful.
5. Keep the implementation readable rather than unnecessarily complex.

Some problems may have multiple valid solutions. Where relevant, I may include alternative implementations to compare different approaches.
